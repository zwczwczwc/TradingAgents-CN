# Index Analysis Service

This is the backend service for **Index Analysis** (指数分析).

## Features
- Market Index Analysis (e.g., CSI 300, S&P 500)
- Macroeconomic Analysis
- Policy Analysis
- Sector Rotation Analysis
- Strategy Advice

## Usage
1. Install dependencies: `pip install -r requirements.txt`
2. Run service: `python -m app` (Defaults to port 8001)
